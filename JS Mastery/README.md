#  JavaScript Mastery — Zero to React-Ready in 12 Weeks

> A comprehensive, deep-dive JavaScript course for freshers who want to move
> beyond "making things work" and truly understand the **how** and **why** of
> the language before transitioning to React.

---

##  Course Structure

### Phase 1 — Core Foundations (Weeks 1–3)

| Week | Theme | Key Topics |
|------|-------|------------|
| [Week 1](Week1.md) | **Engine, Execution & Scope** | V8 engine, call stack, execution contexts, hoisting, TDZ, scope chain, `var`/`let`/`const`, strict mode |
| [Week 2](Week2.md) | **Data Types, Coercion & Memory** | Primitives vs references, stack vs heap, type coercion rules, truthy/falsy, `typeof` quirks, garbage collection |
| [Week 3](Week3.md) | **Functions, Closures & `this`** | Declarations vs arrows, first-class functions, closures deep dive, `this` (4 rules), `call`/`apply`/`bind`, IIFE, higher-order functions |

---

### Phase 2 — Object Mastery & Data (Weeks 4–6)

| Week | Theme | Key Topics |
|------|-------|------------|
| [Week 4](Week4.md) | **Objects, Prototypes & Classes** | Object creation patterns, prototypal inheritance, prototype chain, property descriptors, ES6 classes, `instanceof` |
| [Week 5](Week5.md) | **Arrays, Iterators & FP** | Array methods (map/filter/reduce), building them from scratch, immutability, destructuring, spread/rest, iterators, generators |
| [Week 6](Week6.md) | **Error Handling, Modules & Symbols** | Custom errors, try/catch/finally, defensive programming, ES Modules (import/export), module patterns, Symbols |

---

### Phase 3 — Async & The Browser (Weeks 7–9)

| Week | Theme | Key Topics |
|------|-------|------------|
| [Week 7](Week7.md) | **DOM, Events & Rendering** | DOM tree, traversal/manipulation, addEventListener, bubbling/capturing, event delegation, critical rendering path, reflow vs repaint |
| [Week 8](Week8.md) | **Promises, Async/Await & Event Loop** | Event loop, microtasks vs macrotasks, Promise states/chaining, building Promise from scratch, combinators, async/await |
| [Week 9](Week9.md) | **Fetch, Web APIs & Async Patterns** | Fetch API, AbortController, localStorage, Web Workers, IntersectionObserver, debounce/throttle |

---

### Phase 4 — Advanced Patterns & React Readiness (Weeks 10–12)

| Week | Theme | Key Topics |
|------|-------|------------|
| [Week 10](Week10.md) | **Design Patterns & Architecture** | Observer/Pub-Sub, Factory, Strategy, Proxy/Reflect, composition over inheritance, state machines |
| [Week 11](Week11.md) | **Performance, Testing & Tooling** | Performance profiling, memory leaks, WeakMap/WeakSet, unit testing, bundling/tree shaking, `requestIdleCallback` |
| [Week 12](Week12.md) | **React-Readiness: Build Mini React** | JSX as function calls, Virtual DOM, rendering, reconciliation/diffing, `useState`, `useEffect`, immutable state |

##  How to Use This Course

1. **Read each week's lesson** in order — they build on each other.
2. **Type every code example** yourself — reading is not enough.
3. **Do the exercises** before looking at answers.
4. **Build the milestone project** — this is where real learning happens.
5. **Follow the source links** to go deeper on any topic.
